Each new child uses T3 `delegate_task` with `isolation: "worktree"`, a self-contained brief and unique E2E_PORT/WEB_PORT. The initial nonoverlapping wave was W01 send/copy, W10 MIME-only compatibility and W11 Gmail fixture. Gmail and the first W12 diagnostic privacy slice are now landed. W12 diagnostics/console privacy, W01 durable Sent-copy recovery and W06 live-process uncertain-mutation replay guards are landed. The attempted W11 incoming-fixture child failed at model capacity before checks; W03 owns any necessary direct-caller route updates. W10 remains parked unlanded after two reviews; W05 activation waits for overlapping provider/core work. Queue W03/W05/W06 shared core/store/protocol work behind overlapping W01 changes. Children do not spawn children or edit main. Unknown applicability is investigated before implementation; it is not a reason to invent a service.

Per change: short spec, meaningful failing test, fix and atomic local commits with the AGENTS footer. Run touched-module/direct-caller test files, touched-package types/lint, covered UI spec/visual light+dark checks, and only the affected perf file for a changed hot path. No app build, packaged smoke, full tests/e2e/perf, quiet-window protocol or broad gate replay per fix. Codex code review runs on the worktree, **at most two rounds per series**. Fix round1 findings with regressions; after round2 fix only high-severity correctness/data-loss findings and backlog everything else below.

The orchestrator lands one branch at a time: rebase onto current local main without fetch/merge commits, resolve conflicts and rerun targeted tests/package types, then `merge --ff-only`. If main moves, rebase/retry without force/reset. Update this worklist in a separate docs commit after landing and remove only the finished worktree/branch. Do not push. After active needs-work groups land, announce one final milestone and run typecheck/lint/test/e2e/web/ui-perf/perf plus dist:mac and packaged smoke once; fix failures in small worktrees.
