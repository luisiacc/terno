Forward-observe the real HTTP server's accepted-socket/data events and backend stop entry; preserve their real implementations. Gate the last header bytes. Transport cleanup must not skip backend cleanup on failure. Preserve localhost/token/origin checks and ordinary startup behavior. No arbitrary force timeout, backend abort, retry, swallowed error or widened test limit is a fix. One bounded read-only source critique must challenge the concrete candidate before production.

This candidate adds no polling, timers in production, per-message/list work, remote network, storage/schema/RPC API or product copy. State is at most one closing flag and one close promise per actual host, with listener lifetimes ending at host close. If actual evidence requires a raw-socket inventory or broader backend admission seam, document and refine that boundary before implementation.
