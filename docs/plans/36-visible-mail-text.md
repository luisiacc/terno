## Design and supported semantics

Use parse5 document parsing with scriptingEnabled:false and HTML tree construction/entity decoding and css-tree's declaration-list parser. Traverse iteratively; never recursively walk attacker-controlled depth. Omit hidden attributes, display:none subtrees, head/script/style/template and nonrendered embedded content. Respect inherited visibility:hidden/collapse, with explicit visible descendant override; display:none ancestors cannot be overridden; an explicit supported scalar visible inline display overrides ordinary hidden on that same element. Hidden-until-found remains excluded. Recognize common inline email preheaders using opacity:0 and zero maximum height with hidden overflow. Do not prune font-size:0: descendants can reset it; font metrics/shorthand are outside this local model. Resolve duplicate declarations by importance/order, parse comments/escapes with CSS grammar. Do not build an HTML parser from regexes.

Text normalization collapses HTML whitespace/NBSP to one space, preserves inline word joins and adds word boundaries at blocks/br/table cells. Decode named/numeric entities once, retaining case and visible Unicode. No link target, image alt/attribute, comment or CSS text enters the body. Local extraction is not computed layout: no viewport, external/embedded cascade, geometric clipping, offscreen positioning, transparent color or arbitrary CSS expressions. These are explicitly out of scope, not claimed equivalent to all rendered pixels. The reader's sanitizer already drops embedded stylesheets.

Move the unused htmlToText export from mime.ts into its internal helper module (parent authorized; no workspace consumers). Production parseRaw dynamically imports the heavy async helper only for HTML fallback. One shared first-use task handoff splits parser initialization from the first parse/store slice; later calls await an already resolved promise and create no timer. Browser ESM splits it; desktop single-CJS bundles contain the bytes with deferred initialization, not a separate chunk. Plain mail keeps its existing path. Preserve all MIME/address/Reply-To/attachment behavior and plaintext precedence. Empty alternatives retain PostalMime public-result semantics; only the exact fallback expression changes.
